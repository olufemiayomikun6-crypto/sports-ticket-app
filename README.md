# Sports Ticket App

A simple web app for viewing and booking sports event tickets.

## Project Description

Sports Ticket App is a project that allows users to view sports events and book tickets.

## Main Features

- View sports events
- View event details
- Book tickets
- Select ticket quantity
- View booked tickets

## Technologies

- React
- JavaScript
- HTML
- CSS
- Node.js
- MongoDB
